# Lumen PSX brand assets

Core identity of Lumen PSX. Generated by `scripts/brand/logo.py` (pure geometry, no
fonts) and `scripts/brand/png.py` (PNG icons): change the scripts, never hand-edit the files.

| File | What | Use |
|---|---|---|
| `logo.svg` | **LPSX** in isometric voxel letters, one colour per letter | the primary logo: splash/boot screen, release banners, social cards, README headers, merch |
| `logo-front.svg` | the same LPSX voxel letters seen straight on, with a short extrusion below | headers and heroes where the logo sits in a line of text (the site’s hero) |
| `mark.svg` | the **L** alone: four cubes, one per colour | small sizes: site header, app icons, avatars |
| `favicon.svg` | the mark on a black rounded square | browser favicon |
| `favicon-32.png`, `apple-touch-icon.png` (180), `icon-512.png` | PNG renders of `favicon.svg` (`scripts/brand/png.py`, Pillow) | browsers without SVG favicons, iOS home screen, web manifest |

## Colours (PlayStation-era palette)

Each voxel has a front, a lighter top and a darker side.

| Letter | Colour | Front | Top | Side |
|---|---|---|---|---|
| L | red | `#E4002B` | `#FF5A70` | `#9E001E` |
| P | yellow | `#F5B800` | `#FFD95A` | `#B88A00` |
| S | green | `#00AC8E` | `#45DCBD` | `#00735F` |
| X | blue | `#2E6DB4` | `#6A9FE0` | `#1C4A80` |

The mark stacks green, yellow, red (bottom to top) with the blue cube as the foot.

## Rules

- Prefer black backgrounds (as the site and Lumen's UI); on light backgrounds keep the
  colours, no outlines or effects.
- Don't recolour, rotate, stretch or re-letter it; don't add gradients or glows to the
  voxels.
- It is an original mark that only borrows the era's colours: never place it next to, or
  combine it with, Sony's PlayStation logo.

## Geometry

Isometric projection (30°). Letters are monospaced 6×8 voxels with two-voxel strokes (same
width and weight), extruded 0.55 voxel deep, 2.4 voxels apart (1.5 in the frontal version); the mark uses full cubes. Hidden faces are culled and each face carries
a hairline of its own colour so no seams show between voxels.
